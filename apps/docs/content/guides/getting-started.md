# Getting Started

Welcome to Facet. This guide walks you through installing the component library.

## Installation

Install the core packages:

```bash
pnpm add @fusorb/facet-components @fusorb/facet-tokens
```

## Usage

Import a component and use it:

```tsx
import { Button } from "@fusorb/facet-components";

export default function App() {
  return <Button>Click me</Button>;
}
```

::callout{tone="note"}
Make sure to import the tokens CSS in your app entry point.
::
