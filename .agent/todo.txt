## NEW — INVESTIGATION
[x] Line chart crosshair duplication bug (hovered data pts affected, not region;
    "duplicated crosshair" appearance). Examined crosshair + dot rendering in
    chart.tsx. ROOT CAUSE found (see EP 31 notes):
    - Active data-point DOT uses `transform: scale(1.15)` with NO transformOrigin.
      SVG <circle> default transform-origin is the viewport (0,0), so the hover
      scale shifts the dot centre from (cx,cy) to (cx*1.15, cy*1.15) — the dot
      drifts right/down off the snapped crosshair line (images: with-hover.png).
      Pie slices already set transformOrigin=${cx}px ${cy}px; line dots do NOT.
    - Secondary tension: comment at L970 says "guide line ALWAYS follows raw
      cursor (Recharts pattern)" but code L997 snaps the line (catPos = isSnapped
      ? snapCat : trackCat). For line charts crosshairSnap defaults true, so the
      line snaps (jumps) rather than following the cursor.
    - Bar charts (image 1, dot-not-following): crosshairSnap defaults false →
      dynamic snap within 8px. Current bar behaviour matches desired model; image
      1 likely reflects PRE-3bc29f2 state where line snapped for all types.
    - .log files: trivial chunk-size warnings only (no action).
