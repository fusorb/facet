# Docs archive

This directory holds **archived/superseded planning notes** kept for reference. Historical narrative also lives in `.agent/episodes.md` (tracked canon) and `.agent/logs.txt` (local).

- `planning/` — retired planning docs (e.g. completed/historical gap trackers). Active follow-ups should be promoted back into an active plan or tracked in issues/backlog.
- `rebuild/` — reserved for superseded rebuild drafts if any are retired later.

Active planning lives in `docs/rebuild/` (current: `06-surface-rebuild-delta.md` + `SURFACE-SPEC.md`/companions) and, when needed, `docs/planning/`.
